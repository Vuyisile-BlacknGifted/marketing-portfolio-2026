# Vuyisile Phika Portfolio

A clean, modern growth marketing portfolio built with Next.js and Tailwind CSS.

## Stack

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Framer Motion (subtle section animations)

## Open the portfolio

This portfolio is designed to work as a standalone website. To view it:

1. Open the project folder in your browser or file explorer.
2. Double-click the `index.html` file.
3. The site will load directly from the local files without requiring a server.

## Content updates

Main portfolio content lives in:

- `src/app/page.tsx`

Reusable UI components live in:

- `src/components/cards.tsx`
- `src/components/SectionHeading.tsx`
- `src/components/AnimatedSection.tsx`
